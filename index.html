      Копии перед импортом

      Исходная база не читается. Автоматический импорт заблокирован, чтобы не заменить данные неполной копией. Скачайте исходную запись для восстановления; фотографии и черновики остаются в браузере.

      Данные хранятся в этом браузере и профиле, не на GitHub. В приватном режиме и после очистки они могут быть недоступны. Корень сайта и /preview/ используют отдельные базы. Можно проверить источники без изменения данных или выбрать свой JSON через обычный импорт.

      Диагностика сохранения

      Ничего не переносится автоматически. Сравните источники, названия и цены. Старые примеры не нужно импортировать вместо своей базы. Перед объединением можно скачать каждый источник; применение использует существующую проверку конфликтов и обязательную резервную копию.

      Установка приложения

      Для установки используйте существующую PWA, чтобы сохранить её адрес и ярлык: Открыть страницу приложения. Между отдельными базами данные переносятся только через JSON.

      Android — Chrome

      Откройте эту ссылку в обычном Chrome с интернетом. В меню ⋮ выберите «Установить приложение» либо «Добавить на главный экран» → «Установить». Названия зависят от версии Chrome. Если пункта нет, продолжайте в браузере; установка в этом браузере сейчас недоступна.

      Компьютер — Chrome или Microsoft Edge

      В Chrome нажмите значок установки справа в адресной строке либо ⋮ → «Трансляция, сохранение и отправка» → «Установить страницу как приложение». В Edge: ⋯ → «Приложения» → «Установить этот сайт как приложение». Если пункта нет, этот браузер или профиль не предлагает установку; программа доступна как сайт.

      iPhone или iPad — Safari

      Откройте эту ссылку в Safari, нажмите «Поделиться» → «На экран Домой». Если доступен переключатель «Открывать как веб-приложение», включите его, затем нажмите «Добавить». Нативное окно установки Chrome на iOS не поддерживается.

      После установки дождитесь в меню «Приложение» сообщения «Готово к запуску без интернета». В другом браузере или профиле данные могут храниться отдельно: переносите их только через экспорт и импорт JSON. Старый ярлык не удаляйте, данные не очищайте.
