## Изоляция

Сборка добавляет только `/pr-22/`: 32 файла приложения, manifest и `.nojekyll`.
Пять замен констант выполняются только в соответствующих модулях, остальной код
совпадает с PR №22. Никакие браузерные профили или JSON пользователя не читаются.
Тестовая база при первом открытии пустая; демонстрационные записи не создаются.

| Данные | Собственное имя стенда |
| --- | --- |
| Продукты, цены, рецепты, папки, упаковка | `kitchen-calculator-pr22-preview-v1` |
| Черновики | `kitchen-calculator-pr22-drafts-v1` |
| Фото | `kitchen-calculator-pr22-photos-v1` |
| Резервные копии импорта | `kitchen-calculator-pr22-import-backups-v1` |
| Оформление | `kitchen-calculator-pr22-appearance-v1` |

Корень и привычный `/preview/` собираются из прежних зафиксированных коммитов,
проверяются по всем 182 файлам, затем по 57 реальным HTTPS-ответам до публикации.
После неё проверяются те же файлы и 33 новых ответа стенда. Если main или источник
PR изменился, публикация останавливается. Настройки Pages и основной workflow
`pages.yml` не меняются.

## Короткая проверка на телефоне или компьютере

1. Откройте отдельный адрес `/pr-22/` в обычном Chrome. Вверху указано «PR №22».
   Знакомые записи из другого калькулятора здесь сами не появятся — база отдельная.
2. Создайте тестовый продукт с ценой, полуфабрикат и блюдо. Добавьте папку,
   фотографию и сохраните. Начните изменение рецепта и оставьте черновик.
3. Полностью закройте Chrome и откройте ту же ссылку в том же профиле. Проверьте
   цену, рецепт, папку, фото и предложение восстановить черновик. Повторите три раза.
4. Проверьте экспорт JSON. Импорт применяется только после просмотра изменений
   и вашего подтверждения, с резервной копией перед записью.

Не очищайте данные браузера и не используйте инкогнито для проверки сохранности.
Настоящая база по прежнему адресу не переносится автоматически и не меняется.

`check.cjs` использует исходный проверенный сценарий PR №22 в одноразовых профилях.
Каждый цикл завершает и Chrome, и драйвер; ожидаемые данные обратно не записываются.
Worker запрещает даже чтение других ключей и открытие чужих IndexedDB при обычной
работе. Во всех темах на 1366/390 px проверяются создание через интерфейс, реальные
скачивания JSON, цены, выход, упаковка, две фото, папка, черновик и старая вкладка.
Физический Android и настоящий принтер требуют ручной приёмки.
