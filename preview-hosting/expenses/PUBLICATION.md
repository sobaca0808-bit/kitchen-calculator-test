# Расходы заведения — опубликованный отдельный тест

**Открыть калькулятор:** https://sobaca0808-bit.github.io/kitchen-calculator-test/expenses/

Опубликован и проверен 16 ноября 2026 года. Исходник — **PR №23**,
`1c1fcc057370f04a0451bf62ef6241a1edeb7587`, поверх PR №22. Коммит публикации —
`8cccd70d549b91cd90817941e9602ae509e113da` ветки `preview/browser`.

## Что добавлено

В PR №22 расчёта расходов не было. Новый модуль добавляет заметную вкладку
**«Расходы заведения»** и переключатель **«Учитывать расходы заведения»** в
калькуляционной карте. Аренда, коммунальные платежи, зарплаты и прочие расходы
за месяц делятся на плановые продаваемые порции всех блюд.

Детализация и итоги пересчитываются автоматически. Продуктовая маржа остаётся
отдельной. Итог включает продукты, существующий расчёт упаковки и долю расходов;
на полуфабрикаты накладные расходы не начисляются повторно. Сохранение плана не
меняет поля рецептов, включая метаданные упаковки. Введённая точность сохраняется,
округляются только показанные итоги. Карта повара не содержит финансового блока.

## Короткая проверка владельцем

1. Откройте новую ссылку и вкладку **«Расходы заведения»**.
2. Введите месяц, план порций и четыре суммы, затем **«Сохранить расходы»**.
3. Откройте свою тестовую карточку блюда и включите **«Учитывать расходы заведения»**.
   Измените число порций и сравните две маржи. Проверьте повторное открытие Chrome.

Полный пример с цифрами — в [инструкции](README.md#ручная-проверка).
Это плановая оценка по указанным затратам, не чистая прибыль. Хранилище остаётся
локальным; очистка данных и инкогнито не подходят для проверки постоянного сохранения.
Мобильные сценарии — эмуляция Chrome. Физический Android и настоящий принтер
требуют ручной проверки. Обновление основной версии возможно только после отдельного согласования.
