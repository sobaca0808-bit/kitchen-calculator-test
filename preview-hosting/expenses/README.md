Реальные данные не копируются, первая база пустая. Для теста можно создать свои
записи либо явно экспортировать/импортировать JSON с другого стенда, проверив
просмотр объединения. Никакого автоматического переноса или очистки нет.

## Ручная проверка

1. Откройте **«Расходы заведения»** в основной навигации. Укажите месяц и план
   3 000 продаваемых порций; аренду 60 000 ₽, коммунальные 15 000 ₽, зарплаты
   45 000 ₽, прочие 0 ₽. Должно получиться 40 ₽ расходов на одну порцию.
2. Нажмите **«Сохранить расходы»**, откройте калькуляционную карту блюда и включите
   **«Учитывать расходы заведения»**. Продуктовая маржа показана отдельно.
3. Проверьте детализацию и пересчёт выбранного числа порций. При продуктах 30 ₽,
   упаковке 5 ₽ и цене 150 ₽ полная оценка — 75 ₽, новая маржа — 50%.
4. Проверьте повторное открытие Chrome, JSON, фото и черновик. Изменение месячного
   плана не меняет поля рецепта. Округляются только показанные итоги.

Опубликованные тесты используют одноразовые профили, учебные данные и строгий
запрет доступа к чужим ключам/IndexedDB. Main, рабочий репозиторий и существующие
публикации не меняются; PR №23 не объединяется. Мобильные проверки — эмуляция
Chrome; физический Android и настоящий принтер требуют ручной проверки.
