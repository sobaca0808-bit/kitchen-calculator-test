# Изолированный тест PWA

Адрес: https://sobaca0808-bit.github.io/kitchen-calculator-test/pwa/.
Полный манифест, иконки и SW находятся только под `/pwa/`, scope ограничен этой
подпапкой. Основной калькулятор остаётся b7e391d с прежними файлами и хранилищами;
212 его прежних HTTPS-ответов сверяются до и после публикации.

Тестовое PWA использует пять отдельных имён `kitchen-calculator-pwa-*`, начинает
с пустой базы и не переносит данные автоматически. Основные исходные константы
хранилищ в PR не переименовываются; изоляция выполняется только сборкой стенда.

Установка: обычный Chrome → «Приложение» → дождаться готовности автономной копии →
«Установить приложение», либо меню Chrome ⋮ → «Установить приложение» / «Добавить
на главный экран». После установки открыть иконку «Кухня · тест», отключить сеть
и запустить снова. В разных профилях/браузерах используйте явный JSON-перенос.

Все runtime-ответы живого сайта проверяются без подмены. Только стартовые данные
в одноразовых профилях задаются искусственным fixture; данные владельца не читаются.
Фактическое подтверждение публикации и результатов появится в PUBLICATION.md
после успешного HTTPS- и браузерного прогона. Main и рабочую ссылку не обновлять.
