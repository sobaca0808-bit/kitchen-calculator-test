При желании используйте явный JSON-импорт тестовых рецептов с просмотром изменений;
месячный план переносится вместе с ними, выбор расходов сохраняется у каждого блюда.

## Ручная проверка

1. Заполните и сохраните вкладку **«Расходы заведения»** либо явно импортируйте
   тестовый JSON с настроенным планом.
2. Откройте сохранённую **«Калькуляционную карту»**. Под ингредиентами и упаковкой,
   перед итогами, находится переключатель **«Учитывать расходы заведения»**.
3. Включите его, раскройте **«Расходы по статьям»**. Сравните обычный и новый итог,
   исходную продуктовую маржу, массу и выход. Выключение не удаляет план.
4. Откройте другое блюдо: его выбор независим. Перезапустите Chrome и проверьте
   восстановление выбора. Сделайте экспорт/импорт JSON и повторите проверку.
5. В печати выберите **«Только итоги»** либо **«С детализацией»**. Для полного
   отсутствия цен выберите форму **«Карта повара»**.

Контрольный пример из задания: ингредиенты 188,44 ₽ + упаковка 3,90 ₽ = 192,34 ₽.
Месячные 222 000 ₽ / 3 000 порций дают 74 ₽; при включении — 266,34 ₽. Это учебная
проверка суммы, не перенос реальной рецептуры. В коде приложения надбавка 74 ₽ не задана.

Мобильные проверки — эмуляция Chrome; физический Android и настоящий принтер
проверяются владельцем. До отдельного согласования основная версия не обновляется.
