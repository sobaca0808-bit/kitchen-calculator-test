## Сохранность действующего сайта

GitHub Pages хранит одну публикацию на репозиторий. Поэтому собирается общий
артефакт: прежнее содержимое main `63443c5` без изменения его файлов плюс новый
каталог `/preview/`. Настройки Pages и основной workflow не меняются.
Перед публикацией проверяется, что main не сдвинулся и 25 рабочих файлов
действующего сайта совпадают с этой базой по SHA-256. При расхождении публикация
блокируется. После публикации эти же файлы проверяются ещё раз.

В локальной репетиции сохранены все 149 файлов базового Git-дерева; изменения
добавляются только внутрь `/preview/`. Рабочий репозиторий `kitchen-calculator`
не используется. Новые права публикации или снятие правил окружения автоматически
не запрашиваются и не применяются: отказ GitHub останавливает workflow.

## Данные предпросмотра

В пакет попадают только необходимые файлы из публичного Git-коммита. База,
профили браузера, реальные фотографии и пользовательские экспорты не копируются.
Встроенные начальные данные остаются без закупочных цен.

Четыре прежних постоянных имени хранилищ и новая настройка оформления отделены
от текущего тестового сайта:

- localStorage: `kitchen-calculator-preview-v1` и `kitchen-calculator-preview-drafts-v1`;
- IndexedDB: `kitchen-calculator-preview-photos-v1` и `kitchen-calculator-preview-import-backups-v1`.
- Настройка оформления в localStorage: `kitchen-calculator-appearance-preview-v1`.

При упаковке исходников заменены только эти пять строковых литералов и текст отметки
предпросмотра/названия вкладки. Формат JSON, расчёты, слияние, фотографии,
черновики и печать прежние. `preview-version.json` содержит исходный SHA и
контрольные суммы всех файлов. Домен github.io общий, поэтому очистка всех
данных домена в настройках браузера затронула бы оба приложения; публикация
такой очистки не выполняет.

## Проверки

На исходнике выполнены 207 Node-проверок и 669 браузерных сценариев: по 217 прежних
в каждой теме и 18 новых общих. В 24 парах A4 совпали текст, число страниц и пиксели.
Одноразовые копии тестов отличаются только пятью
ожидаемыми именами хранилищ, исходные тесты PR №20 не изменяются.
Дополнительно пройдены две строгие проверки на 1366/390 px: запрещены обращения
к любым иным ключам localStorage и базам IndexedDB; защищённые учебные значения
старых хранилищ остаются прежними. Проверены восстановление черновика,
сохранение двух фото, перезагрузка, JSON-экспорт и объединение с резервной копией,
смена всех тем без изменения базы и запоминание оформления.

Workflow после развёртывания проверяет 57 HTTPS-файлов (25 основной версии,
31 предпросмотра и его manifest), запускает по 20 UI-сценариев в трёх темах и две строгие
проверки на реально опубликованном адресе в Chrome. Скриншоты компьютера/телефона
и JSON-отчёт сохраняются в артефакте `browser-preview-proof` страницы Actions.
Физический Android не эмулируется полностью: используется мобильный viewport
и touch-режим настольного Chrome.

согласования и здесь не выполняется.
