# Единая версия перед выпуском — проверенный стенд

**Открыть калькулятор:** https://sobaca0808-bit.github.io/kitchen-calculator-test/final/

Проверено 16 ноября 2026. Стенд имеет **отдельную первоначально пустую базу**.
Настоящие данные автоматически не копировались и не удалялись. Для проверки своей
базы можно явно экспортировать JSON из прежней версии и импортировать его сюда
через существующий просмотр объединения и резервную копию.

## Состав и зависимости

Подготовлен [единый PR №25](https://github.com/sobaca0808-bit/kitchen-calculator-test/pull/25)
из `release/unified-review` в main. Все исходные PR остаются открытыми и не объединены.

| PR | Согласованная функция | Основа |
| --- | --- | --- |
| 20 | Три темы оформления | main |
| 22 | Надёжное сохранение и безопасное восстановление | PR 20 |
| 23 | Расходы заведения / план месячных порций | PR 22 |
| 24 | Переключатель расходов с выбором отдельно у каждого блюда | PR 23 |

Это последовательная история, каждый предыдущий PR уже является предком следующего.
Финальная ветка создана от PR 24; патчи повторно не применялись. Все **36 файлов
приложения** совпадают с согласованным PR 24. Добавлены только отчёт и полный CI.
Формулы, структура базы, фотографии, печать и дизайн не переписывались.

## Результаты

- **253 теста логики + 715 браузерных сценариев** прошли в
  [полном Chrome CI](https://github.com/sobaca0808-bit/kitchen-calculator-test/actions/runs/43865137744)
  именно на финальном исходном коммите. Полный локальный прогон также завершился с кодом 0.
- Проверены цены, продукты, вложенные полуфабрикаты, потери и автоматический выход
  блюда, временный пересчёт порций, упаковка, продуктовая маржа, фотографии, папки,
  черновики, сохранение, старый JSON, повторный импорт, конфликты и резервные копии.
- [Публикация и реальные HTTPS-проверки](https://github.com/sobaca0808-bit/kitchen-calculator-test/actions/runs/43867024573)
  завершились успешно: **25 сценариев расходов** и **6 полных жизненных циклов**
  нового стенда. Ответы приложения не подменялись. Проверены три темы, 1366/390 px,
  отсутствие горизонтальной прокрутки, консоль и запрет доступа к чужим хранилищам.
- В каждом жизненном цикле выполнено три полных запуска Chrome, всего **18 запусков**:
  продукты/цены, полуфабрикат, блюдо, папка, упаковка, обе фотографии, цена продажи,
  оформление и незавершённый черновик сохраняются; JSON скачивается через интерфейс.
- Вкладка расходов, автоматическое обновление аренды/зарплаты и отдельный флаг
  каждого блюда работают. Контрольная учебная сумма **192,34 → 266,34 ₽** подтверждена;
  исходная продуктовая маржа, масса и выход не меняются, двойного учёта нет.
- A4 с детализацией, только итогами и без финансов прошёл проверку; обе финансовые
  PDF контрольного блюда занимают по одному листу. Прежние варианты фото и длинные
  таблицы проверены полным набором. Физический принтер не использовался.
- Сохранены **291 прежний файл**, до публикации сверены **163 HTTPS-ответа** прежних
  версий, после — **200** вместе с новым стендом. Корень и `/preview/`, `/pr-22/`,
  `/expenses/`, `/expense-toggle/` остались прежними; их браузерные проверки тоже прошли.
- Main остался `63443c5`, источники PR 20/22/23/24 не изменены. Рабочий репозиторий
  `kitchen-calculator`, настройки Pages и пользовательские базы не менялись.

Мобильные проверки выполнялись в Chrome с узким экраном и касаниями. Физический
Android, камера и настоящий принтер остаются для ручной проверки владельцем.
