# Единая финальная проверка перед выпуском

Адрес: https://sobaca0808-bit.github.io/kitchen-calculator-test/final/

Источник — PR №25, ветка `release/unified-review`, `662a12a`.
Это единая история main → PR 20 → PR 22 → PR 23 → PR 24, без повторного применения
патчей. Код приложения совпадает с утверждённым PR 24; формулы и интерфейс не меняются.

Пять собственных хранилищ используют префикс `kitchen-calculator-final-`:
`preview-v1`, `drafts-v1`, `photos-v1`, `import-backups-v1`, `appearance-v1`.
Начальная база пустая. Данные других версий автоматически не переносятся и не удаляются.
При необходимости пользователь явно импортирует JSON через существующий просмотр
объединения с резервной копией. Старые адреса и их файлы сохраняются.

Перед публикацией сравниваются хеши всех прежних файлов и HTTPS-ответов.
После публикации проверяются реальный HTTPS-адрес, 25 сценариев расходов и 6
полных жизненных циклов в трёх темах на компьютере и мобильном экране (по три
запуска Chrome в каждом). Ответы приложения не перехватываются; разрешён только
вспомогательный учебный fixture в пустом временном профиле.

`prepare-checks.py` добавляет финальный URL в разрешённые адреса временной копии
прежних тестов расходов. `check.cjs` использует прежний lifecycle без изменения
его проверок, с финальными URL/ключами и блокировкой любых чужих хранилищ.

Публикация подтверждена успешным Actions. Результаты, снимки и A4 — в
[PUBLICATION.md](PUBLICATION.md). Main и основная рабочая ссылка не обновлялись.
