кухня» — по умолчанию, её CSS и акварель сохранены побайтно. «Графит» использует

рецептов и JSON; ошибка настройки не изменяет базу. Прежние функции фотографий,
черновиков, расчётов, упаковки и импорта сохранены. A4 использует прежние правила.
