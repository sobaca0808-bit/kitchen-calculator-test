## Что проверять вручную

Открыть адрес в Chrome на компьютере и телефоне. Проверить кремовые карточки,
бронзовые кнопки, поиск, прокрутку длинной формы и доступность «Сохранить» внизу.
Сохранить учебный рецепт, обновить страницу и повторно открыть карточку.
Проверить выбранные фотографии и диалог печати A4.

Автоматические мобильные проверки выполнены в Chrome с эмуляцией ширины и touch,
а не на физическом Android. Настоящая камера телефона и принтер не проверялись.
Из этой Cloud-среды внешний просмотрщик не смог открыть домен; успешное открытие
и работа подтверждены Chrome и HTTP-проверками на сервере GitHub Actions.

Адрес и ключи хранилищ предназначены для следующих предпросмотров. Автоматической
синхронизации с main нет. Обычная публикация из main пока заменяет общий артефакт
Pages без `/preview/`, поэтому после неё предпросмотр требуется выпустить снова
с новым проверенным базовым SHA. Основной workflow в этой задаче не изменялся.
