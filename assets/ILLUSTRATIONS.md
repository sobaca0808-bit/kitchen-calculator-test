# Изображения светлой кухни

Созданы специально для проекта инструментом генерации изображений 15 ноября 2026 года.
Сторонние фотографии, стоки, внешние CDN и реальные данные кухни не использовались.

- `watercolor-kitchen.webp`: оригинальная акварельная композиция с малиной, черникой, яблоком, грушей, клубникой, инжиром, смородиной и листьями. Четыре небольшие группы по краям, прозрачный центр, без повторяющегося орнамента. 1536×1024, прозрачность сохранена. Файл оптимизирован в WebP без изменения композиции; CSS дополнительно смягчает рисунок молочной вуалью.
- `graphite-kitchen.webp`: отдельная иллюстрация для «Графита»: травы, артишок, чеснок, груши, венчик и салфетка в сдержанных серебристых и холодных зелёных оттенках. 1536×1024, прозрачный центр, около 194 КиБ.
- `sage-kitchen.webp`: отдельная иллюстрация для «Шалфея»: базилик, груша, травы, чеснок, горох и мука. 1536×1024, прозрачный центр, около 181 КиБ. Розовые и оранжевые мотивы не используются.
- `../tests/fixtures/berry-galette.webp`: созданное учебное изображение яблочной галеты с ягодами на светлой тарелке. Используется только автоматическими проверками и снимками интерфейса. В начальные рецепты и пользовательскую базу не добавляется, в runtime-пакет предпросмотра не включается.

Исходные PNG сохранены в рабочем каталоге генерации; в Git включены оптимизированные WebP. Утверждённая ягодная иллюстрация не менялась при добавлении тем. Загружается только активная фоновая композиция; миниатюры в переключателе нарисованы CSS и не загружают остальные изображения. Печатные формы не используют фоновую иллюстрацию.
