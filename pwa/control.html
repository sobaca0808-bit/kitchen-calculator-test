Как установить на Android
  1. Откройте этот адрес в обычном Chrome с интернетом.
  2. Нажмите «Установить приложение» либо откройте меню Chrome ⋮ → «Установить приложение» или «Добавить на главный экран».
  3. Запускайте калькулятор через появившуюся иконку. Дождитесь готовности автономной копии перед работой без сети.
Данные и перенос через JSON

В разных браузерах, профилях или способах установки хранилище может отличаться. Если после установки библиотека пуста, откройте прежнюю версию, нажмите «Экспорт JSON», затем выберите этот файл через «Импорт JSON» в приложении. Проверьте список изменений перед применением. Ничего не переносится и не заменяется автоматически.

Как обновляется приложение

Обновление загружается отдельно. Текущая форма не перезагружается. Сохраните работу и закройте все окна этого приложения; новая версия откроется при следующем запуске. Обновление не удаляет рецепты, фотографии или резервные копии.
