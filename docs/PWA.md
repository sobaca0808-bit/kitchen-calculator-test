# Устанавливаемый кухонный калькулятор

Основа — проверенный main `b7e391d`. Работа выполняется в отдельной ветке,
без изменения опубликованного рабочего калькулятора и без автоматического слияния.

## Установка на Android

1. Откройте тестовый адрес в обычном Chrome: https://sobaca0808-bit.github.io/kitchen-calculator-test/pwa/.
2. Откройте **«Приложение»**, дождитесь **«Готово к запуску без интернета»**.
3. Нажмите **«Установить приложение»**, если кнопка доступна. Иначе откройте меню
   Chrome **⋮ → «Установить приложение»** или **«Добавить на главный экран»**
   и подтвердите установку. Название тестовой иконки — **«Кухня · тест»**.
4. Запустите через появившуюся иконку. Выключите сеть и откройте приложение снова.
5. Создайте тестовый рецепт, сохраните, закройте приложение и проверьте его повторно.
   Проверьте фотографии, расходы, экспорт/импорт JSON и печать.

На компьютере в поддерживаемом Chrome/Edge используйте кнопку установки в адресной
строке или меню браузера. Приложение запускается отдельным окном.

## Данные

Исходные ключи основной базы, фото, черновиков, расходов и оформления не меняются.
Код калькуляции, упаковки, JSON, фотографий и черновиков остаётся прежним.

Только сборка тестового адреса использует пять отдельных имён
`kitchen-calculator-pwa-*`; она начинает с пустой базы. Реальные записи и старые
демо не копируются автоматически. Создайте тестовые записи или явно импортируйте
JSON с предварительным просмотром и резервной копией.

Chrome обычно разделяет данные обычного сайта и установленного приложения в том
же профиле. В другом браузере, рабочем профиле или при другом способе установки
хранилище может отличаться. Если библиотека пуста, откройте прежнюю версию,
нажмите **«Экспорт JSON»**, затем **«Импорт JSON»** в нужном приложении, проверьте
предложенные изменения и примените. Ничего не заменяется без подтверждения.

## Офлайн и обновления

- Manifest использует относительные id/start_url/scope, display standalone и
  PNG 192/512 плюс отдельную maskable-иконку 512 с безопасной центральной зоной.
- Service Worker кеширует 42 статических файла, около 1 МБ, включая все три темы.
  Пользовательские записи, фото, импортируемые JSON и посторонние страницы в кеш
  приложения не записываются. Фото по-прежнему хранятся в IndexedDB.
- Каждый файл проверяется по SHA-256 до завершения установки. Незавершённая или
  повреждённая копия не становится активной, прежняя версия остаётся доступной.
- Новая версия ждёт закрытия всех окон прежней. Принудительной активации,
  захвата уже открытых страниц и автоматической перезагрузки формы нет.
  Сохраните работу, закройте все окна этого приложения и запустите снова.
- Очистка касается только устаревших завершённых кешей данной области SW.
  Более новые ожидающие установки и кеши других приложений не удаляются.
  localStorage и IndexedDB Service Worker не очищает и не изменяет.
- SW перехватывает только точные пути своего приложения. Для других калькуляторов,
  неизвестных маршрутов, blob-снимков и пользовательских JSON сохраняется обычное
  поведение сети. Тестовый SW ограничен `/kitchen-calculator-test/pwa/`.

## Сборка и выпуск

`scripts/build-pwa.py` выполняется после упаковки HTML и ресурсов. Версия зависит
от содержимого статических файлов и SW. Неподготовленное исходное дерево не
регистрирует SW — обычный калькулятор продолжает работать без изменения данных.

`scripts/build-pwa-preview.py` готовит изолированную тестовую сборку. Для будущего
разрешённого выпуска подготовлен PWA-совместимый release builder: все 35 исходных
модулей/стилей/иллюстраций сравниваются с утверждённой версией, HTML может содержать
только дополнительные блоки PWA. Кеш формируется после окончательного HTML,
включая метку рабочей версии и единые параметры JS/CSS.

Текущая задача публикует только новый тестовый адрес. Перед будущим слиянием и
выпуском необходимо подтвердить проверку владельцем и закрепить тестовый PWA
в наборе сохраняемых стендов; текущий main и рабочую ссылку сейчас не обновлять.

## Автоматические проверки

`tests/pwa-build.test.py` проверяет иконки/maskable, пути, полноту, хеши и
воспроизводимость сборки. `tests/pwa.browser.test.js` запускает реальные SW:
офлайн-правки/фото/расходы/JSON/A4, холодный запуск, независимость от main,
несохранённый черновик, несколько вкладок и отказ повреждённого обновления.

`tests/pwa-install.browser.test.js` проверяет настоящую установку через backend
Chrome и отдельное standalone-окно в графическом тестовом профиле под Xvfb.
Headless Chromium может отключать системную установку (`kWebAppDisabled`);
это не заменяется имитацией standalone. Фактический результат CI фиксируется
в отчёте и артефактах. Физический Android здесь недоступен, поэтому установку
на телефоне и съёмку камерой проверяет владелец по инструкции выше.
