# Домашняя кулинарная книга

Основа: PR #37, `feature/sintez-unified-workspace`, `cbf42009a0001bc3e91c6d305ebe302bcc2f3382`. Отдельная ветка `feature/home-cookbook-no-finance`; родительский PR и main не меняются.

Домашний режим использует прежние редакторы и единую базу, но показывает только рецептуру, продукты, полуфабрикаты, фотографии, порции, выход, время, инструкции, заметки, папки и избранное. Скрыты финансовые поля, списочные суммы, мобильные итоги, профессиональные настройки карточки и финансовая детализация сравнения при импорте. Для домашнего просмотра/печати повторно использована существующая форма без цен, с названием «Рецепт». Выбор фотографий при домашней печати независим от профессионального.

Поля профессионального редактора остаются смонтированными и скрытыми: переключение режимов сохраняет даже незавершённые числовые строки и ошибки. Их нельзя случайно заменить пустыми значениями. Если в профессиональном поле остался неверный ввод, явное сохранение блокируется; исправьте его в профессиональном режиме. Обычное домашнее редактирование сохраняет прежние цены, упаковку, расходы и прочие поля.

JSON остаётся полной резервной копией **всей** базы, включая профессиональные данные и фотографии. Отсутствие цен на домашнем экране не делает JSON обезличенным файлом для публичной передачи. В домашнем сравнении импорта профессиональные поля скрыты, однако выбранное действие применяется к полной записи. Существующий предварительный просмотр, подтверждения конфликтов и резервная копия перед импортом сохранены.

## Проверки

`node --test tests/home-cookbook.test.js` — проекции без цен, граммовки полуфабрикатов, старые записи, неизменяемость данных и полный JSON.

`node tests/home-cookbook.browser.test.js` на собранном PWA — ПК/телефон, CRUD, обе фотографии, четыре режима печати, скрытые поля/черновики, сравнение импорта и полные финансовые данные.

`python3 scripts/check-home-cookbook-core.py` — побайтная защита 80 файлов, включая расчёты, базы, JSON-движок, фотографии, PWA и четыре рекламных кадра, плюс 17 обработчиков сохранения/черновиков (в saveDraft разрешён только текст уведомления).

CI `.github/workflows/home-cookbook.yml` также запускает прежние функциональные сценарии на трёх темах, существующие проверки интерфейса/профессионального A4, сборки и строгого verifier, настоящую установку и безопасное офлайн-обновление PWA в Chrome Windows/Linux.

Итоговые ссылки и фактические результаты будут добавлены после завершения CI и проверки отдельной публикации. Физическая установка на Android проверяется владельцем; эмуляция мобильного Chrome не заменяет проверку устройства.

## Android: ручная проверка

1. Перед изменениями скачайте JSON в Настройках. Используйте учебные записи.
2. Откройте отдельный тестовый адрес в Chrome, выберите «Для дома». Проверьте отсутствие цен в списках, продукте, полуфабрикате, рецепте, печати, настройках и сравнении импорта.
3. Создайте продукт без цены, полуфабрикат и рецепт с ним; добавьте фото, выход, время, инструкции. Сохраните, закройте Chrome и откройте вновь.
4. Перейдите в профессиональные режимы: прежние цены, упаковка, расходы и показатели должны остаться. Вернитесь домой: видна только рецептура.
5. Экспортируйте и повторно импортируйте JSON через предпросмотр. Проверьте фотографии и отсутствие дубликатов.
6. Дождитесь готовности офлайн в Настройках, установите через меню Chrome «Добавить на главный экран / Установить приложение». Включите авиарежим, запустите по значку, отредактируйте рецепт и сохраните. После повторного запуска проверьте правку и фото. Проверьте печать без фото и с каждым снимком.

Никаких изменений основной публикации, main, формул и четырёх вступительных кадров. Автоматического объединения нет. Отдельный стенд использует прежние пять SINTEZ-тестовых ключей, общие с другими SINTEZ-стендами; рабочее хранилище не переносится. Перед ручными тестами обязательно скачайте тестовый JSON.
