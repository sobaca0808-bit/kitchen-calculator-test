# Главный экран с тремя направлениями

Основа — проверенная `9787f93` из PR №33. Main `9f45d02` и старые публикации
не меняются. Отдельная ветка `feature/sintez-work-modes` и дочерний PR в
`release/sintez-safe-release` сохраняют все предыдущие доработки.

## План и границы

1. Заменить только главный экран и его навигационный фасад: три равные карточки,
   компактные настройки, матовая фактура и тонкие золотые линии.
2. Использовать существующий `KitchenNavigation` для всех переходов. Режим —
   это набор быстрых входов и URL-параметр, а не новая база, тариф или фильтр данных.
   Все остальные функции доступны через «Все разделы и инструменты» и прежние
   вкладки рабочего калькулятора.
3. Переместить те же DOM-элементы PWA в настройки. Сохранить фоновый клиент,
   worker и обновления. Критические ошибки доступны через компактное сообщение.
4. Проверить исходный runtime, мобильные экраны, клавиатуру, черновики, JSON,
   печать, офлайн, обновление и настоящую desktop-установку. Опубликовать только
   дополнительный стенд `/sintez-modes/`, сохранив все предыдущие файлы.

Расчётные модули, схемы и ключи хранения, фото, импорт/экспорт, резервные копии,
технологические карточки и A4 не изменяются. 67 прежних файлов, включая
презентацию, иконки, клиент и алгоритм PWA, сверяются побайтно с основой.
В index.html разрешён только блок `SINTEZ:HOME`.

## Поведение

Обычный запуск сразу показывает три направления. Презентация остаётся
доступна из настроек и по отдельному `presentation.html`. Главная возвращает
к выбору направления; «Разделы режима» — к инструментам выбранного режима.
Открытые поля остаются в прежнем редакторе; «Продолжить открытую работу»
возвращает их. Сохранение черновика использует существующий механизм.

Домашний режим выделяет продукты, рецепты и новый расчёт. Профессиональный —
рецепты, техкарты, полуфабрикаты, продукты, калькулятор и фото. Бизнес — рецепты,
калькулятор, расходы, продукты, полуфабрикаты и упаковку. Это навигационные
приоритеты: остальные разделы и JSON доступны во всех трёх направлениях.
Техкарты и фото открывают существующую библиотеку рецептов, без дублирования.

PWA-кнопки и готовое обновление видны в настройках. Неудачная подготовка кеша
или ошибка сохранения оставляет доступное предупреждение и переход к прежним
инструментам. Критическая ошибка не маскируется декоративным оформлением.

## Риски и согласования

Значительная переработка архитектуры не требуется. Хранилищ для режимов нет:
URL-параметр `mode` не попадает в JSON и не пишет localStorage. У нового
тестового PWA собственный id `/kitchen-calculator-test/sintez-modes/`;
существующие установленные приложения и их id/scope/start_url не изменяются.
Данные стенда — прежняя общая SINTEZ-тестовая база, автоматического переноса
из рабочей `/pwa/` нет. Старую PWA удалять или переустанавливать не нужно.

Новый SVG с фактурой — локальный файл около 0.4 КБ, без сторонних изображений.
Рабочие темы и печатные стили не затрагиваются.

Отдельного согласования требуют окончательное распределение быстрых входов
между режимами и последующий выпуск в main. Функциональных ограничений нет.
Основной выпуск должен учесть сохранение нового тестового маршрута и явное
утверждение runtime в release guard. Существующий основной builder не меняется
и не принимает этот новый интерфейс автоматически. PR №33 остаётся отдельной
зависимостью; ничего не объединять и не публиковать в рабочую версию автоматически.
Физический Android и iOS проверяет владелец; эмуляция экрана не заменяет телефон.
