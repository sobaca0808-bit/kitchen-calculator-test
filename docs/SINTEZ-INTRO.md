# «СИНТЕЗ МЕРЫ»: презентация и существующий главный экран

Дочерняя ветка `feature/sintez-intro` от `feature/sintez-home`, PR №30,
коммит `871155948134353c4219e6c1aa4dcb039848ea68`.
PR этой работы направлен в `feature/sintez-home`, а не в main.
Утверждённое [техническое задание](SINTEZ-INTRO-TASK.md) сохранено вместе с работой.

## Поведение

Четыре исходных JPEG сохранены побайтно, в порядке: знакомство, дом, повар,
бизнес. Подписи соответствуют утверждённому HTML. На телефоне подпись находится
под полным изображением; на широком экране — на прежнем затемнении.
Ни один снимок не растягивается и не обрезается. Иллюстративные экраны явно
отмечены как иллюстрации. Внешних изображений, шрифтов и зависимостей нет.

Кнопки «Назад», «Далее», четыре индикатора, свайпы и стрелки клавиатуры
управляют слайдами. Home/End открывают первый/последний кадр. Автопросмотр
запускается только вручную и останавливается на бизнесе, при ручном переходе,
закрытии и скрытии вкладки. Он никогда самостоятельно не входит в приложение.
Полноэкранная кнопка доступна только при поддержке Fullscreen API.

«Пропустить» и «Начать работу» закрывают модальное окно над тем же главным
экраном с шестью действующими плитками. Признак просмотра хранится отдельно:
`kitchen-calculator-sintez-presentation-seen-v1`. Ошибка записи показывается
сообщением; приложение остаётся доступным. Никакие поля базы не меняются.

Любая существующая запись базы, черновиков или оформления, в том числе пустая
или повреждённая, исключает автоматическую презентацию. При ошибке чтения
новый пользователь не предполагается. Прямые `?section=...`,
`#storage-diagnostics` и параметры import/restore/recovery обходят приветствие.
Явная диагностика сохраняет прежние разрешённые действия чтения источников.
Презентация сама не читает другие базы и не переносит их.

«Настройки → Посмотреть презентацию снова» открывает тот же диалог, сохраняя
DOM редактора, черновик, позицию страницы и фокус. Закрытие возвращает в настройки.
Escape и «Назад» браузера закрывают диалог без записи признака просмотра;
«Вперёд» браузера открывает его снова. Обновление незавершённого первого просмотра
возвращает его, повторный запуск после подтверждённого просмотра — главный экран.
Перезагрузка повторного просмотра из настроек возвращает в настройки.

## Данные и публикация

Новый маршрут `/sintez-intro/` использует **те же пять тестовых имён хранения,
что `/sintez/`**. Второй базы нет, копирования и миграции нет. Поэтому сохранённые
на этом устройстве тестовые записи доступны с обоих адресов. Рабочий калькулятор,
main, PWA и остальные тестовые пространства отделены прежними ключами.
Пользователь с существующими данными сразу увидит главную; презентация доступна
через настройки. Синтетические данные проверок создаются только в одноразовых
браузерных профилях.

Старый welcome.html, весь прежний JS, стили, формулы, фото, JSON, печать
и обработчики редактора не изменены. Проверяется сравнением с PR №30 и main.
Публикация должна добавлять только `/sintez-intro/`; все 296 ранее доступных
HTTPS-файлов, включая 39 файлов `/sintez/`, проверяются до и после по SHA-256.
Нельзя объединять PR, автоматически обновлять main или заменять прежний стенд.

У исходного `/sintez/` нет собственного Service Worker. Новый маршрут также не
регистрирует его: PWA в `/pwa/` не изменяется. При потере сети уже загруженная
презентация и открытый калькулятор работают; первый запуск/перезагрузка офлайн
на новом маршруте не обещается. Кнопка установки не добавляется.

## Ручная проверка на компьютере и Android

1. Открыть новый тестовый адрес. Если есть прежние тестовые данные, нажать
   «Настройки → Посмотреть презентацию снова». Для первого входа использовать
   отдельный профиль/инкогнито; отсутствие основной базы в нём нормально.
2. Пролистать все четыре кадра. Последний — «Для бизнеса». Проверить точки,
   свайп, клавиши и обе кнопки входа; после входа видны шесть рабочих плиток.
3. Открыть адрес повторно — презентация не навязывается. Из настроек открыть
   её снова, закрыть Escape/кнопкой/«Назад» браузера и проверить возврат.
4. Создать пробный рецепт, приложить фото, изменить технологию без сохранения,
   вернуться на главную и посмотреть презентацию. Продолжить открытую работу:
   поля и фото должны остаться. После обновления восстановить черновик.
5. Проверить экспорт/импорт JSON, расходы и A4 на своих тестовых записях.
   Ничего не удалять и не очищать данные сайта ради проверки первого входа.

Физический Android проверяет владелец; автоматические мобильные сценарии
используют Chromium с сенсорным вводом и соответствующими размерами.
