# Единая сборка СИНТЕЗ МЕРЫ на Vue 3

Ветка `integration/sintez-vue3` продолжает PR №45 (`7545295`), который включает PR №44 (`5cac849`) и предыдущие изменения поиска, расходов, журнала, режимов и технологических карт. Коммит `c9f6cd5` добавляет исторические замеры и две проверки интерфейса. Графики в `docs/vue-measurements` относятся к сравнению №44 и №45. Новые измерения проводятся при сборке на том же исполнителе для №45 и интеграции.

Сборка использует Vue 3.5.46 и существующие модули расчётов и хранения. Для запуска из исходников нужны Node.js 22, npm и Python 3. Выполните `npm ci`, `npm run build`, затем `npm run dev` и откройте адрес с путём `/kitchen-calculator-test/sintez-vue3/`. В каталоге dist появятся сайт и `sintez-mery-vue3.zip`. Для запуска из ZIP распакуйте его и раздайте файлы через HTTPS или локальный HTTP-сервер. Полная установка PWA использует указанный путь.

У стенда отдельные ключи книги, черновиков, темы и презентации, отдельные базы фотографий и копий импорта и собственная область сервис-воркера. Для проверки можно использовать вымышленные рецепты либо явно импортировать резервную копию JSON в настройках. В ZIP входят только файлы приложения.

Автопроверки запускает `.github/workflows/sintez-vue-integration.yml`. В артефактах сохраняются PDF форм А4, скриншоты, результаты работы с 10 000 рецептов и сравнительные измерения на пяти размерах библиотеки. Браузерные сценарии используют одноразовые профили. Архив сравнивается по каждому файлу с протестированным сайтом, а модули, стили и изображения — с версией PR №45 с поправкой на отдельные имена хранилищ.
