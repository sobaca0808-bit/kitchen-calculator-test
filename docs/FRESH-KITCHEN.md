# Светлая кухня — переработка PR №20

Работа продолжается в `feature/warm-professional-kitchen`, в существующем PR №20.
Основная ветка и действующая основная страница остаются прежними. Обновляется
только отдельный предпросмотр `/kitchen-calculator-test/preview/`.

## Визуальная система

| Элемент | Цвет |
| --- | --- |
| Фон | Молочный `#FFF9F4` |
| Рабочие карточки | Светлый кремовый `#FFFDF9` |
| Основные действия | Приглушённый ягодный `#A65B77` |
| Декоративные акценты | Пудровый `#F4D9E2` |
| Вторичные элементы и таблицы | Светлый шалфей `#B8CBB4`, мягкие зелёные поверхности |
| Небольшие детали | Бронза `#A7835C` |
| Основной текст | Графит `#343A38` |

Навигация, заголовки, формы и расчётные блоки разделены светлыми поверхностями.
Кнопки имеют согласованные hover/active/focus/disabled-состояния. На узком экране
четыре раздела расположены в два ряда с доступной высотой кнопок от 44 px.
Основные действия остаются в существующей закреплённой панели.

Для фона создана оригинальная акварельная композиция с прозрачным центром.
Она хранится локально, не повторяется плиткой, адаптируется к ширине и смягчается
молочной вуалью. Текст и таблицы располагаются на непрозрачных поверхностях.
Заголовок библиотеки также закрыт светлой поверхностью, чтобы рисунок не мешал
чтению. [Происхождение изображений](../assets/ILLUSTRATIONS.md).

## Проверки и ограничения

Исходные `styles.css`, все файлы `js/` и формулы не меняются. Новая тема целиком
ограничена `@media screen`. Версия CSS в ссылке обновлена, чтобы после обновления
страницы браузер запросил новое оформление. Формат JSON, фото, черновики,
упаковка, финансовые показатели и алгоритм объединения остаются прежними.

Набор проверки темы включает редакторы на 320/390/768/1366 px, клавиатуру,
контраст, длинную форму, закреплённую панель, окно импорта, пустые/загруженные
фото, удаление учебного фото только из черновика и сохранность исходной карточки.
Для двух форм A4 и четырёх вариантов фотографий сравниваются текст, число страниц
и пиксели каждой печатной страницы с отключённой/включённой экранной темой.
Полный `node scripts/check-preview.mjs` завершился с кодом 0: **198 Node-проверок
и 217 браузерных сценариев**, без ошибок и пропусков. В 96 проверенных сочетаниях
текста/поверхности контраст не ниже **4,71:1**. Все восемь пар A4 совпали по тексту,
числу страниц и пикселям. [Машиночитаемый отчёт](screenshots/berry-kitchen/theme-proof.json).
Подробности — в [TESTING.md](../TESTING.md).

Физический Android и принтер требуют ручной проверки. Автоматические мобильные
проверки выполняются в Chromium с узким экраном и эмуляцией touch.

## Ручная приёмка

1. Открыть отдельный предпросмотр и обновить страницу. Проверить молочный фон, акварель, ягодные кнопки и зелёные вторичные элементы.
2. Открыть все четыре раздела, попробовать поиск и перейти клавишей Tab между полями и кнопками.
3. Открыть рецепт без фото: заглушки должны быть маленькими. В редакторе проверить галерею и камеру, затем загрузить один и два учебных снимка.
4. Сохранить рецепт, обновить страницу, проверить сохранность снимков, ингредиентов и цены. Прокрутить длинный редактор до конца: кнопки доступны, поля не перекрыты.
5. В обеих формах карты проверить печать A4 с фотографиями и без них. Цветной декор не должен печататься.
6. Проверить экспорт/импорт учебного JSON и восстановление незавершённого черновика. Рабочую базу в предпросмотр автоматически не переносить.
