# Единая стеклянная система

Основа — PR №34 (`b44c1f5`). Отдельная ветка `feature/sintez-glass`; main
`9f45d02` и все предыдущие публикации сохраняются.

План: добавить общий screen-only слой CSS поверх существующего интерфейса,
применить его к главной, рабочим формам, библиотеке, таблицам, расходам,
фотографиям, импорту и настройкам. Три палитры используют одинаковую структуру
и один локальный кухонный фон. Выбор остаётся в прежнем ключе оформления.
На новом входе без сохранённого выбора используется тёмная кухня; сохранённые
розовая/зелёная/графитовая темы не перезаписываются. Одна визуальная система,
одна прежняя SINTEZ-тестовая база. Автоматической миграции нет.

Основные риски — контраст над фотографией, нагрузка blur на телефоне, длинные
формы и каскад старых стилей. Поэтому размытие ограничено крупными внешними
панелями (16 px / 8 px на телефоне); строки и поля используют плотные лёгкие
заливки. Для отсутствующего blur, reduced transparency и forced colors есть
варианты без размытия. Декор не перехватывает касания. Печатный CSS не меняется.

Рабочие функции, формулы, связи, JSON, фото, черновики и PWA worker остаются
побайтно прежними. В appearance.js меняется только явно включаемая исходным
HTML тема по умолчанию, без записи в хранилище. В навигации — подпись темы
и цвет браузерной панели. Архитектура и реальные функции не переписываются.
Отдельного раздела аналитики в существующем приложении нет: новые фиктивные
экраны не создаются. Существующие финансовые блоки получают общий стиль.
Системные confirm/file picker браузера сохраняются: их вид определяет ОС.

Тестовый маршрут — `/sintez-glass/`, отдельный id PWA. Все пять имён хранилищ
остаются прежними SINTEZ-тестовыми; отдельной базы для тем или режимов нет.
Публикация должна сохранить 464 существующих HTTPS-ресурса и все старые файлы.
Ничего не объединять; основной runtime guard не утверждать автоматически.

Фон `assets/sintez-glass-kitchen.webp` создан специально для задачи инструментом
генерации изображений OpenAI, без внешних стоковых фотографий. Исходник оставлен
в workspace/generated_images. WebP 1536×1024 — 76 562 байта, мобильный 768×512 —
24 900 байт. Обе версии включаются в офлайн-кеш. Их не нужно загружать из облака.

Проверки: защита исходников, все прежние логические и функциональные сценарии,
новая матрица визуальных тестов трёх тем, локальные и публичные режимы, реальные
JSON/фото/черновики/A4, офлайн/обновление/установка PWA. Старые проверки точного
цвета непрозрачной темы заменяются проверками новой общей стеклянной системы,
а не выдаются за неизменившийся визуальный контракт. Физический Android требует
ручной проверки владельцем.
