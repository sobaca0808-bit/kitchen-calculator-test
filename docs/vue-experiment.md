# Эксперимент Vue 3

Исходная точка — PR №44, `5cac84953c47713cc8e1396be9fbf880ea933c71`. Рабочая ветка эксперимента — `experiment/vue3-workspace`.

## Сборка и запуск

Требуются Node.js 22 с npm и Python 3. В чистой рабочей копии выполните `npm ci` и `npm run build`. Папка `dist` содержит самостоятельный веб-сайт, включая Vue, вспомогательные файлы и автономную копию. Для повторной локальной сборки укажите новый каталог командой `python3 scripts/build-sintez-release-candidate.py --target vue --output <новый-каталог>` после `npm run build:vue`. Открывайте сборку через HTTP на localhost либо через HTTPS. Разместите папку по пути `/kitchen-calculator-test/sintez-vue/` для установки с её собственным идентификатором PWA.

## Архитектура и данные

Компоненты в `vue/` обслуживают режимы, меню, презентацию, библиотеку, черновики, карточки, редакторы, просмотр фотографий, финансовый журнал и предпросмотр импорта. Проверенные модули расчёта, транзакции импорта, обработка фотографий, восстановление черновиков и печать продолжают обслуживать эти экраны. Компоненты Vue также выводят позиции упаковки в рецепте, выбор оформления, слоты фотографий, справочные окна и источники для восстановления. Для файловых полей, печати, установки PWA и транзакций сохранены обработчики браузерных API. Полноэкранный просмотр фотографий загружается при первом открытии. Для установки PWA сервис-воркер заранее сохраняет и проверяет его файл.

Длинные списки держат в DOM строки видимой области и небольшой запас. Идентификаторы, зависимости полуфабрикатов и названия для поиска индексируются по состоянию библиотеки. Для чтения корректного JSON больше не требуется глубокая копия всей разобранной базы. При записи проверяются состояние предыдущей версии и байты, прочитанные после сохранения.

Эксперимент использует отдельные ключи библиотеки, черновиков, оформления и презентации, отдельные базы IndexedDB для фотографий и копий перед импортом и отдельную область кэша. Библиотека рецептов продолжает сохраняться синхронно в localStorage. Допустимый объём зависит от квоты браузера, размеров рецептов и доступного места. Чтобы опробовать свою библиотеку, экспортируйте JSON в настройках старого стенда и импортируйте его в настройки нового. Черновики хранятся отдельно от JSON сохранённых карточек.

## Воспроизведение замеров

Для сценариев нужен Playwright 1.62.1 и Chromium; переменная `CHROMIUM_PATH` указывает на исполняемый файл. Запустите `node tests/vue-performance.cjs <папка-эталона> before.json`, затем ту же команду для новой сборки с `after.json`. Для сравнения используйте один браузер и последовательные запуски. Команда `python tests/vue-performance-report.py before.json after.json <каталог>` строит таблицы и графики с помощью matplotlib. Одно измерение после двух requestAnimationFrame оценивает интервал до возможности отрисовки. Выборка JS-кучи после принудительной сборки мусора не включает графическую память.
