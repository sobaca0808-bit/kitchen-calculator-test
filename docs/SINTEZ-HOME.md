# «СИНТЕЗ МЕРЫ» — главный экран

Основа — main `9f45d02`. Рекламная презентация используется только как визуальный
образец: графитовые панели, светлые линейные иконки, сдержанное золото и холодный свет.
Фотографии, вымышленные экранные данные и рекламные обещания в программу не переносятся.
Новые иллюстрации и внешние зависимости не добавляются; иконки — локальный inline SVG.

Шесть плиток открывают существующие разделы. «Калькулятор» вызывает действующую
форму нового блюда, сохраняя обычные проверки ухода из редактора. Плитка «Мои рецепты»
открывает библиотеку, «Настройки» — те же три темы, импорт/экспорт JSON и справочник
упаковки. Упаковка также доступна в прежней навигации. Возврат «Главная» не заменяет
DOM редактора: открытые поля сохраняются, черновик рецепта отправляется в существующее
автосохранение. При обработке фото или резервной копии переход блокируется.

Для дома/повара/бизнеса подготовлены три структурных области. Это подписи будущих
направлений, не фиктивные переключатели и не разные формулы или копии библиотеки.

## Проверка

1. Открыть `/sintez/` — видны все шесть плиток. Проверить каждую и возврат «Главная».
2. Изменить цену продукта без сохранения, вернуться на главную и нажать
   «Продолжить открытую работу»: поле остаётся. Попытаться открыть другой раздел,
   отклонить подтверждение — сохранённая цена остаётся прежней.
3. Изменить технологию рецепта, вернуться на главную, обновить страницу и открыть
   библиотеку. Восстановить черновик, проверить поля и обе фотографии.
4. В «Настройки» выбрать тему, экспортировать JSON и проверить его импорт. Импорт
   использует прежнюю проверку конфликтов и резервное копирование.
5. Закрыть и открыть Chrome; проверить рецепты, продукты, цены, фото, папки,
   упаковку, расходы и тему. Печатная карта использует прежний A4, без нового меню.
6. Проверить 320/390 px на телефоне, 768/1024 px на планшете и 1366 px на компьютере.
   Физический Android требует ручной проверки: автоматические тесты используют Chrome.

Стенд использует пять отдельных имён `kitchen-calculator-sintez-*`, начинает с пустой
базы и ничего автоматически не переносит. Главный сайт, `/pwa/` и прежние стенды должны
сохраняться побайтно. Настройки Pages не менять, main и PR автоматически не объединять.

Автопроверка `scripts/check-sintez-core.py` сравнивает прежние ресурсы с main и
разрешает только добавленное меню/узкий интерфейс навигации. Полная матрица прежних
сценариев открывает существующее рабочее пространство через `?section=dish`, отдельные
тесты проверяют настоящий новый стартовый экран и изолированную сборку. Сравнение
пикселей прежней ягодной темы исключает только добавленную навигационную полоску.
При будущем выпуске новый runtime необходимо отдельно утвердить в release builder;
в текущей задаче публикуется только новый тестовый адрес.
