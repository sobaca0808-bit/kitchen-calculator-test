СИНТЕЗ МЕРЫ — утверждённый логотип СМ, поварской колпак, золотая дуга и график.
Источник: оригинальный PNG, 1254x1254.
icon-N.png — обычные иконки. icon-maskable-N.png — вариант с безопасными полями на тёмном фоне для Android. favicon.ico — браузер.
Не менять дизайн. Подключить через manifest.webmanifest (192/512, purpose:any; maskable отдельно), favicon, apple-touch-icon. Учитывать реальный scope и start_url PWA, не менять storage keys и SW без проверки.
Если система обрезает маску, проверить центрирование на Android. Не обещать мгновенное обновление значка уже установленной PWA.
