Иконки созданы для проекта по существующему знаку «К»: собственная простая
композиция, без сторонних фотографий. PNG с буквенным знаком, цветами ягодной
темы и отдельным непрозрачным maskable-вариантом. У maskable-иконки весь знак
расположен внутри центральной безопасной окружности радиусом 40% стороны.
