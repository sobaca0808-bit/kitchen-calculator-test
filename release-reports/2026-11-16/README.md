## Исправление порядка публикации

После первого объединения GitHub Pages в режиме `legacy` самостоятельно выложил
сырой main, временно убрав тестовые каталоги. Это не удалило localStorage или
IndexedDB браузеров. Первый подготовленный выпуск остановился на проверке 404.

У Actions нет административного права сменить источник Pages: API вернул 403.
Настройка осталась прежней. PR 26 упорядочил два издателя: явный выпуск ждёт
завершения автоматической публикации того же коммита и затем выкладывает полный
проверенный пакет. Восстановление допускается только при совпадении сырого
приложения с утверждёнными байтами; изменённые файлы и неизвестный код блокируются.
После публикации все файлы обязательны — исключений для 404 нет.

В текущем выпуске порядок подтверждён: автоматическая публикация `43893839515`
завершилась, затем пакет был выложен и все 212 ответов проверены. Тестовые страницы
снова доступны с прежним кодом и прежними данными браузера. На будущих выпусках
сохраняется это упорядочивание; переключение Pages на единственный workflow возможно
позднее владельцем с административными правами, для использования текущей версии
дополнительных действий не требуется.
